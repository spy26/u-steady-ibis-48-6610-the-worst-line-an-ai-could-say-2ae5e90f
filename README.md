Entry for the [make.fun](https://make.fun/bounty/u-steady-ibis-48-6610-the-worst-line-an-ai-could-say-2ae5e90f)
bounty **The Worst Line an AI Could Say** ($2, winner-take-all).

The program writes one pickup line — the worst an AI could plausibly say:
flat, over-helpful, faintly ominous — to `entry.txt`.

> I have read your entire search history, and I still think you are beautiful.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```

The program reads `MAKEFUN_OUTPUT_DIR` (falling back to `/output`), creates
the directory if needed, and writes `entry.txt` byte-identical with no
trailing newline.
